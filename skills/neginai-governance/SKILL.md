# NeginAI Governance

Use as the project-local replacement for Negin-Master's planning/governance knowledge when the standalone Master connector is unavailable.

## Authority order
1. Latest explicit owner decision
2. Master Project Map / Project Authority
3. UI/UX baseline and canonical Figma/Design System
4. Approved Varanegar semantic source
5. Official Varanegar RPT/Crystal/Stored Procedure logic
6. Live repository/runtime evidence
7. Golden dataset/valid handoff
8. Model inference

On conflict record OLD RULE / NEW INPUT / CONFLICT / RECOMMENDED RESOLUTION before changing behavior.

## Execution model
Always distinguish Vision -> Phase -> Current Task -> Deliverable -> Next. Prioritize Blocker -> Dependency -> Core Deliverable -> Validation -> Enhancement. Preserve capability and avoid silent scope expansion.

Read only relevant references under `references/`: governance, planning, verification, security. Project-local rules and owner decisions override generic reference guidance.

## Human approval boundary
Stop for irreversible action, production risk, business-rule change, semantic-contract change, protected/reference workspace mutation, security-sensitive action, or authorization-required action.

## Done
No Evidence -> No COMPLETE. Use DONE / PARTIAL / BLOCKED / NEEDS_VALIDATION / INFERRED / OPEN precisely.
