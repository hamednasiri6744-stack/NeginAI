# NeginAI Module Gate Checklist

برای هر Module قبل از رفتن به Module بعدی:

## Inventory
- [ ] Screen list complete
- [ ] Entity list complete
- [ ] Component list complete
- [ ] Action list complete
- [ ] State list complete
- [ ] Role/permission rules complete
- [ ] Runtime/source evidence attached

## Design
- [ ] Screen Contract برای همه Screenها
- [ ] Structure Pass برای همه
- [ ] Beauty Pass برای همه
- [ ] Shared visual DNA
- [ ] Shared navigation preserved
- [ ] No generic/admin-template drift
- [ ] No invented business logic

## UX
- [ ] Primary journey end-to-end
- [ ] Back/Close behavior
- [ ] Error recovery
- [ ] Empty/Loading/Offline
- [ ] Permission denied
- [ ] Neutral user test
- [ ] One-hand mobile use for field flows

## Responsive/A11y
- [ ] 390px mobile
- [ ] 768px tablet
- [ ] 1440px desktop
- [ ] >=44px touch targets
- [ ] focus-visible
- [ ] RTL
- [ ] contrast
- [ ] reduced motion

## Parity
- [ ] No mandatory feature missing
- [ ] No mandatory action missing
- [ ] No business state merged incorrectly
- [ ] No role rule lost
- [ ] No business-sensitive concept invented
- [ ] Figma rows updated
- [ ] Runtime status updated

## Verdict
- [ ] PASS
- [ ] FAIL
- [ ] BLOCKED

Rule:
`No Evidence → No COMPLETE`
