# Comparator معنایی Candidateهای P3 ـ ۲۰۲۶-۰۸-۲۹

شش candidate فرمان گزارش به ۳۸ جفت Case هم‌نوع نرمال‌شده تبدیل شد: Authorization شش، Concurrency دو، Failure Injection هجده، Idempotency شش و Success شش جفت. هر شش candidate دست‌کم یک جفت قابل‌مقایسه دارد.

Precondition exact، outcome exact، assertion-list exact و full exact همگی صفر است. آرایه‌های `expected` پایه فقط assertion محسوب شده‌اند، نه outcome label؛ بنابراین نبود label پایه به برابری ساختگی تبدیل نشده است.

Normalization فقط مسیر adjudication را باز می‌کند و هیچ‌گاه Print، Export، Completion، Statement mutation یا Result parity را هم‌معنا اعلام نمی‌کند. Candidate/Case accepted، اجرا، additive و readiness صفر و lower bound طراحی ۱۴۰۴ باقی ماند.
