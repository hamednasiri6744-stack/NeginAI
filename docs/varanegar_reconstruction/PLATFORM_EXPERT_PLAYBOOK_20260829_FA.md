# Playbook تخصصی Platform

هفت مسیر evidence-first برای Release ناقص، Retry تکراری، اختلاف Audit/Outbox، Backup بدون Restore proof، Failover/Rollback mixed-version، نشت Secret/PII و Transport/HTTP ناامن طراحی شد. هر مسیر ۹ گام دارد و پیش از Deployment، Retry، Restore، Failover، Rollback، Repair یا تغییر Traffic متوقف می‌شود. هیچ رخداد واقعی تشخیص داده یا عملیاتی اجرا نشده است.
