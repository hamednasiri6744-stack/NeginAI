# دفتر شواهد Golden Case و UAT — ۱۴۰۵/۰۶/۰۷

این دفتر مرز میان «طراحی تست» و «اثبات اجرا» را صریح می‌کند. ۷۷ مورد موجود، سناریوهای synthetic برای فرمان‌ها هستند؛ هیچ‌کدام اجرا، تطبیق اثر، یا تأیید مالک محسوب نمی‌شوند.

## نردبان شواهد

1. `DESIGNED_SYNTHETIC`: قرارداد تست، بدون ادعای اجرا.
2. `EXECUTED_ISOLATED`: اجرای ثبت‌شده روی پایگاه هدف ایزوله و fixture مصنوعی.
3. `RESULT_PARITY_PROVEN`: تطبیق خروجی/اثر legacy و هدف بدون اختلاف توضیح‌نداده‌شده.
4. `OWNER_APPROVED`: پذیرش شواهد نام‌دار توسط مالک کسب‌وکار.

وضع فعلی: فرمان‌ها ۷۷ طراحی synthetic و صفر اجرای معتبر دارند؛ ۲۰ سطح گزارش مالکیت فنی بسته‌شده ولی صفر تطبیق نتیجه و صفر Golden Value تأییدشده دارند. بنابراین UAT-ready و pilot-ready هر دو صفرند و ریسک‌ها ۸۴ باقی می‌مانند.
