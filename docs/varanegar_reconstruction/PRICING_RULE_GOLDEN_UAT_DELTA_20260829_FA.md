# Golden/UAT Delta قواعد قیمت‌گذاری — ۲۰۲۶۰۸۲۹

۶۴ Case موجود برای چهار فرمان Save/Delete دوباره استفاده می‌شوند و تکرار نشده‌اند. ۲۸ Case جدید، هر کدام هفت سناریو، چهار شکاف را پوشش می‌دهند: تغییر اولویت، Compile/Validation شرط، تخصیص و ثبت Linear Discount، و تعهد انتشار/Replication.

مجموع طراحی پذیرش Pricing برابر ۹۲ است. همه `DESIGNED_NOT_EXECUTED` هستند و اجرای آن‌ها فقط در محیط ایزوله با Rule AST مصنوعی، Harness نویسنده‌های موازی، Fault injection، Comparator اثر/Explain و سیاست تأییدشدهٔ مالک مجاز است. هیچ نتیجهٔ Runtime یا UAT ادعا نشده است.
