# ماتریس شکاف خانواده‌های Assertion/Effect در P3 ـ ۲۰۲۶-۰۸-۲۹

۳۸ جفت فرمان گزارش در شانزده خانوادهٔ عمومی و ویژهٔ گزارش مقایسه شد. همهٔ جفت‌ها دست‌کم یک overlap دارند، اما family-set دقیق صفر و عدم‌تقارن assignment برابر ۱۷۴ فقط‌جدید در برابر ۶۷ فقط‌baseline است.

سمت جدید در هر ۳۸ جفت File/Artifact، Render/Print Completion و Per-item partial outcome را بیان می‌کند، ولی Result/Content parity صریح صفر است. baseline این چهار خانواده را به‌ترتیب در ۶، صفر، صفر و فقط دو جفت دارد. Audit جدید/پایه ۳۸/۱۸، Outbox برابر ۰/۲۵، Transaction برابر ۰/۹ و Version برابر ۰/۱۲ است.

Classifier فقط routing heuristic است. حتی overlap کامل عمومی، Fixture/result value یا برابری معنایی را ثابت نمی‌کند؛ پذیرش، اجرا، additive و readiness صفر و lower bound طراحی ۱۴۰۴ باقی می‌ماند.
