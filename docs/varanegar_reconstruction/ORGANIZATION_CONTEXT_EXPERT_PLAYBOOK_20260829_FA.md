# Playbook تخصصی Organization Context

هفت مسیر برای mixed context، مرز تاریخ مفقود/بسته، تفاوت event و selector، ناسازگاری StockDC، lifecycle سال، exception بیش‌ازحد و publication ناقص تعریف شده است.

هر مسیر نه گام evidence-first دارد، فقط hash و ContextSnapshotId را نگه می‌دارد و پیش از تغییر تاریخ/context، pointer rewrite، relation repair، cache refresh یا replay متوقف می‌شود. نتیجه فقط یکی از `NATURAL_BEHAVIOR/DATA_DEBT/BUG/UNPROVEN` است.
