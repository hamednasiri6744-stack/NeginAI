# Golden Caseهای تطبیق بین‌ماژولی — ۱۴۰۵/۰۶/۰۷

این بسته ۳۵ سناریوی مصنوعی و اجرا‌نشده را برای هفت لبهٔ حسابداری، خزانه و توزیع تعریف می‌کند؛ برای هر لبه پنج حالت `MATCHED`، فقط‌مبدأ، فقط‌مقصد، Crosswalk متعارض و اختلاف Scope/Version وجود دارد.

قضاوت روی پنج محور مستقل انجام می‌شود: هویت، دامنه، نسخه، وضعیت و اثر ماندگار. بنابراین برابری مبلغ پرداخت و رسید شرط هویت نیست، Batch چندمبدأیی خطا نیست، نبود فیزیکی خروج مدرک ابطال نیست و `MAX(id)` وضعیت جاری را ثابت نمی‌کند.

تمام Caseها `DESIGNED_NOT_EXECUTED` هستند. اجرای آینده فقط در مقصد ایزوله، با Fixture مصنوعی، Fault Injection، مقایسهٔ رسید Legacy/Target و سیاست‌های تأییدشدهٔ Expected Absence و Cancellation مجاز است. این بسته هیچ مجوز Pilot یا Command-ready ایجاد نمی‌کند.
