# Playbook تخصصی خروجی‌های گزارش — ۱۴۰۵/۰۶/۰۷

شش Playbook برای Batch جزئی، Render بدون Completion، چاپ تکراری/پس از ابطال، Export با محتوای متفاوت، Completion کاذب Healthy Cardex و Import/Export بانکی طراحی شد.

روش واحد Evidence-first است: هویت درخواست و نسخه‌ها pin می‌شوند، رسیدهای Render/Print/Audit/File/Treasury جدا خوانده می‌شوند، نتیجه فقط یکی از رفتار طبیعی، بدهی داده، Bug یا اثبات‌نشده است و پیش از Reprint/Replay/Repair توقف می‌شود.

هیچ رخداد واقعی تشخیص، اصلاح، چاپ مجدد یا Replay نشده است.
