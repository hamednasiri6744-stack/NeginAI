# دلتا‌ی Traceability و Risk سازمان و Context

پنج شاهد به ۱۰ نیازمندی، ۳۵ پیوند ماژولی و ۴۵ پیوند روی ۹ ریسک موجود متصل شده‌اند. نیازها ContextSnapshot immutable، تفکیک سال‌ها، relation معتبر DC/Office/Stock، چهار مفهوم تاریخ، fail-closed boundary، مجوز server-side، publication اتمیک، exception محدود، lineage بازنشستگی و read-back را پوشش می‌دهند.

ثبت پایهٔ ۸۴ ریسک و ۳۴۳ انتساب ثابت است؛ ریسک تازه، closure و runtime readiness promotion همگی صفرند.
