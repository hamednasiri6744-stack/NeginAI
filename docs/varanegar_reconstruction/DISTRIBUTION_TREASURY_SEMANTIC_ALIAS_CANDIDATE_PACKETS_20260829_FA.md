# Packetهای کاندید Semantic Alias توزیع و خزانه ـ ۲۰۲۶-۰۸-۲۹

از ۳۰ هم‌پوشانی `casefold(action)+kind`، ۲۴ مورد متعلق به Distribution و ۶ مورد متعلق به Treasury است. Action و Kind در همهٔ ۳۰ جفت برابرند، اما فقط ۵ Outcome label عیناً برابر و هیچ Assertion list عیناً برابر نیست.

بنابراین همهٔ Packetها `REVIEW_REQUIRED` هستند و Auto-accept ممنوع است. داوری باید Setup/Precondition، نگاشت واژگان Outcome، Assertion/Effect class، Policy version، نقش پاسخ‌گو و تاریخ انقضا را ثبت کند.

Accepted semantic equivalence، additive count، execution، owner approval، command readiness و pilot readiness همگی صفرند و lower bound طراحی ۱۴۰۴ ثابت است.
