# دلتا‌ی Traceability و Risk Master Data

پنج شاهد به ۱۰ نیازمندی، ۴۰ پیوند ماژولی و ۵۰ پیوند روی ۱۰ ریسک موجود متصل شده‌اند. نیازها aggregate نسخه‌دار، child relations، party roles/PII، quarantine، crosswalk namespace، merge برگشت‌پذیر، retirement، atomic receipt، retry read-back و bounded read model را پوشش می‌دهند.

ثبت پایهٔ ۸۴ ریسک و ۳۴۳ انتساب ثابت است؛ ریسک تازه، closure و runtime readiness promotion صفر است.
