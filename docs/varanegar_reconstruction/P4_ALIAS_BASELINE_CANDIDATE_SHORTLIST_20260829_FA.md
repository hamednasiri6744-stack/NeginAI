# Shortlist شواهد Baseline برای P4 ـ ۲۰۲۶-۰۸-۲۹

سه Packet/۲۱ Case export فقط‌خواندنی به سه سطح پایه متصل شد: Read مدل statement بانکی و دو Export-file برای Production detail و Stock reference. این سه reference در مجموع ۱۴ Case پایه و ۱۰ kind-overlap دارند.

مالکیت هر سه سطح بسته و Result parity برای هر سه applicable است، اما Result parity proven برابر صفر است. به‌ویژه Read مدل بانکی فقط candidate برای مرز Export است و هم‌عمل بودن آن‌ها فرض نمی‌شود.

هیچ exact action، semantic equivalence، fixture/result parity، acceptance یا اجرا از shortlist استنتاج نشده است. lower bound طراحی ۱۴۰۴، Risk/Trace برابر ۸۴/۳۴۳ و readiness صفر باقی می‌ماند.
