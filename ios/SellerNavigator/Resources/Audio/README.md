# Persian navigation prompts

Add professionally recorded, short MP3 files with these exact names before release:

- `route_started.mp3`
- `turn_left.mp3`
- `turn_right.mp3`
- `continue_straight.mp3`
- `off_route.mp3`
- `arrived.mp3`
- `stop_skipped.mp3`

These files are intentionally not generated by browser TTS or an AI API. Dynamic values such as distance and street name are shown visually until a licensed Persian prompt set is supplied.
